# CI workflow - 2026-06-05

GitHub Actions CI for panacea-front. Runs on push to `main` and on every pull request.

## Pipeline (.github/workflows/ci.yml)

ubuntu-latest, Node from `.nvmrc` (22), `npm ci`, then lint, typecheck, build
(`vue-tsc -b && vite build`), and test (`vitest run`). `permissions: contents: read` and a
`cancel-in-progress` concurrency group are set.

Lint stays non-strict (`eslint .`, no `--max-warnings`): the repo carries ~237 pre-existing
`vue/max-attributes-per-line` warnings (prettier disagrees with that rule), so warnings must not
fail the gate. Errors do.

## Verification

file parses as valid YAML.
